1. Confirm exercise matches

The closest exercise name is preselected, prioritizing Hevy exercises already used in your routines. Check each match and change it if needed; saving these choices confirms them.

2. Map active training days to routines

Each active day needs its own Hevy routine. If a routine repeats an exercise, choose the exact occurrence for each LiftTracker exercise.

3. Review the full sync

Review every routine before the first write. LiftTracker will prepare all mapped routines for the selected week. Each exercise gets one prescribed top set, then template sets minus one five-rep mini sets at the load derived from 13 reps. Warmups and special sets stay intact.

Sync updates Hevy routines; it does not create a completed workout or launch Hevy. Conflicts stop the batch before any write. Hevy saves routines one at a time, so a connection failure during saving can leave some routines updated; check status and review again before retrying.
